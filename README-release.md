# OpenFBX

OpenFBX is a lightweight 3D model viewer and FBX editor for 64-bit Windows.

1. Keep all files and folders together.
2. Launch `openfbx.exe`.
3. Drag a model into the window or use **File > Open Model**.

FBX, OBJ, and DAE work without extra software. GLB, glTF, Blender, and STL
conversion requires Blender 4.2 or newer. Set `OPENFBX_BLENDER_PATH` when using
a portable Blender installation.

Default shortcuts include Ctrl+O to open, Ctrl+S to save, Ctrl+Z to undo,
Q/W/E/R for select/move/rotate/scale, F to focus, and Space to play or pause.
Shortcuts can be changed under **Preferences > Edit Hotkeys**.
